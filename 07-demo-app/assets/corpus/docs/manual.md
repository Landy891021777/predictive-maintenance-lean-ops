# 渦扇引擎健康監測維修手冊（模擬）

> 🟡 模擬文件（數值取自真實資料）

## 1. 適用範圍與使用說明

本手冊適用於本機隊 100 台渦扇引擎（ENG-001 至 ENG-100）的健康監測與維修作業。
機隊運轉條件為單一飛行條件（海平面），主要失效模式為高壓壓縮機（HPC）性能衰退，
對應 NASA CMAPSS FD001 資料集的設定。

每台引擎每個運轉週期（cycle）回傳一筆讀數，共 21 個感測器。其中 6 個感測器在本機隊全程為定值、不具監測價值，
其餘感測器的正常範圍與退化趨勢見第 2 章。健康狀態由 VAE 模型自動判讀（見第 3 章），
判為 Warning 時依《異常處置 SOP》分級處理。

*來源：本手冊為模擬文件；運轉條件與失效模式依 CMAPSS FD001 資料集說明*

## 2.6 高壓壓縮機衰退的典型徵兆

高壓壓縮機（HPC）性能衰退時，最具代表性的感測器變化（依與剩餘壽命的相關程度排序）：
- Sensor 11（Ps30，高壓壓縮機出口靜壓）上升（r = -0.70）
- Sensor 4（T50，低壓渦輪（LPT）出口總溫）上升（r = -0.68）
- Sensor 12（phi，燃油流量與 Ps30 之比）下降（r = +0.67）
- Sensor 7（P30，高壓壓縮機出口總壓）下降（r = +0.66）
- Sensor 15（BPR，旁通比）上升（r = -0.64）
- Sensor 21（W32，低壓渦輪冷卻引氣流量）下降（r = +0.64）
- Sensor 20（W31，高壓渦輪冷卻引氣流量）下降（r = +0.63）
- Sensor 2（T24，低壓壓縮機（LPC）出口總溫）上升（r = -0.61）
- Sensor 17（htBleed，引氣焓值）上升（r = -0.61）
單一感測器偏離正常範圍不一定代表故障；應以模型綜合判讀與連續讀數趨勢為準。

## 3. 健康狀態自動判讀原理

每筆讀數由 VAE（變分自編碼器）模型自動判讀為 Healthy 或 Warning：
1. 21 個感測值經 MinMaxScaler 正規化
2. VAE encoder 將讀數壓縮為 2 維潛空間座標
3. 在 14,441 筆歷史訓練讀數中找出潛空間距離最近的一筆（1-NN）
4. 若該筆歷史讀數當時的剩餘壽命 ≤ 67 cycles，判為 Warning，否則為 Healthy

「最近距離」越大，代表這筆讀數越不像任何已知的歷史讀數，可作為判讀信心的參考。
模型特性是偏向寧可誤報、不要漏判，因此 Warning 需經覆核（見《異常處置 SOP》）。

## 4. 定期巡檢項目

不論模型判讀結果為何，每台引擎仍需執行定期巡檢，以涵蓋模型可能漏判的情況：
- 每 50 cycles：目視檢查壓縮機葉片、確認感測器接線與讀值合理性
- 每 100 cycles：比對 Sensor 4、Sensor 11、Sensor 7 與正常範圍，記錄趨勢
- 任何 cycle 若有感測器讀值超出第 2 章正常範圍 25% 以上，視為感測器異常，先排除儀器問題再判讀健康狀態
巡檢結果記錄於交接班紀錄。

*來源：巡檢週期與項目為模擬的作業規範*
