# 🛠 NASA Turbofan Engine Health Monitoring Project  

---

##  What — 專案在做什麼  

本專案以 **NASA Turbofan Engine Degradation Simulation Data** 為基礎，  
建立一個能從多維感測器數據中自動學習「設備健康狀態」的嵌入式模型。  

透過 **VAE（變分自編碼器）** 進行特徵壓縮與表徵學習，  
在無需人工標註的情況下自動區分健康與異常行為，  
並以距離閾值方式實現 **早期異常偵測（Early Fault Detection）**。  

最終成果是一個能將高維感測資料轉換成低維健康向量的模型，  
可視化不同引擎的健康軌跡，並計算異常偵測準確率。  

---

##  Why — 為什麼要做  

現今製造業（特別是半導體、汽車、航太等產業）中，  
設備的 **預防性維修（Predictive Maintenance）** 是關鍵競爭力。  

然而：  
- 感測器資料量龐大且多維；  
- 故障樣本稀少；  
- 傳統監測方法對非線性變化不敏感。  

因此需要能從高維感測資料中自動學出健康分佈與異常模式的 AI 模型。  
**VAE 的嵌入能力** 能讓模型在潛在空間（latent space）中捕捉健康 → 故障的變化，  
對應到半導體或 IoT 領域中「從系統訊號辨識異常行為」的實際需求。  

這能展示妳：  
- 有能力處理高維時序感測資料；  
- 理解 representation learning 的實際應用；  
- 能用非監督學習方法解決少標籤問題。  

---

##  How — 怎麼做  

### 1️⃣ 資料前處理與標籤建立  
- 使用 **NASA CMAPSS dataset**（train/test/RUL）。  
- 對每台引擎建立 Remaining Useful Life（RUL）。  
- 移除低變異感測器欄位，標準化資料。  

---

### 2️⃣ Feature Engineering  
- 根據 RUL 將資料切成「健康」與「不健康」階段。  
- 保留關鍵感測器：  
  `sensor_2, 3, 4, 7, 8, 9, 11, 12, 13, 14, 15, 17`。  

---

### 3️⃣ 模型建構  
- 使用 **VAE 架構** 學習感測資料的潛在分佈（embedding）。  
- 將輸入特徵壓縮至低維 latent space。  

---

### 4️⃣ 異常偵測  
- 建立一組 **support set**（代表異常樣本）。  
- 比較新資料與 support set 在 embedding 空間的距離。  
- 根據 validation set 調整閾值，於 test set 驗證效果。  

---

### 5️⃣ 模型評估  
- 指標：Precision、Recall、F1-score、Confusion Matrix。  
- 可視化健康與異常分佈。  

---

### 6️⃣ 成果呈現  
- 整理關鍵圖表：  
  - Loss Curve  
  - Latent Space Clustering  
  - RUL Trend  
- 撰寫 3–5 句說明：  
  > 「模型如何協助實務中預測設備壽命、偵測早期故障徵兆。」

- 一個可展示於履歷的 AI 健康狀態辨識模型  
- 完整流程說明（資料 → 特徵 → 模型 → 評估）
